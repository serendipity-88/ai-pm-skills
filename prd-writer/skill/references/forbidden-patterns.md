# 禁用表达与不确定性标记

## 禁用表达

| 类型 | 禁用 | 替代 |
|------|------|------|
| 口语化 | "我觉得"、"看起来"、"可能" | 用数据或事实陈述 |
| 空洞修饰 | "非常"、"特别"、"显著" | 用具体数据（+7.16pt） |
| 模糊量词 | "大量"、"很多"、"若干" | 用具体数字（约 2.76 亿） |
| 过度承诺 | "一定能"、"必将" | "预计"、"目标值" |
| 感叹语气 | 感叹号、emoji（⚠️ 除外） | 陈述句 |
| 竞品品牌名 | 微信支付、抖音 | "主流短视频平台"、"其他支付方式" |
| AI 套话 | "本模块解决的核心问题是..." | 事实陈述式定位（"XX页面，用于XX+XX+XX"） |
| 视觉参数 | "38px白色加粗字体"、"12px圆角" | "以设计稿为准" |

## 不确定性分级标记

| 确定性 | 标记方式 | 示例 |
|--------|---------|------|
| 已确定 | 直接陈述 | "支持组合支付" |
| 需确认 | 红色+待X | `<font color=#DF2A3F>待技术确认</font>` |
| 暂推迟 | 灰色文字 | `<font color=#8A8F8D>非本期</font>` |
| 已放弃 | ~~删除线~~ | "~~涉及多端改造，成本较高~~" |

---

## 情态词使用规范

以下词汇**极少使用或不使用**（基于 23 篇 PRD 量化分析）：

| 词 | 频次 | 建议 |
|----|------|------|
| 应该 | 3 次 | 几乎不用，直接陈述 |
| 必须 | 9 次 | 极少使用 |
| 务必 | 0 次 | 从不使用 |
| 确保 | 5 次 | 极少使用 |

**应使用的表达方式**：
- 肯定能力："支持X"（~370+ 次）
- 义务要求："需要X" / "需X"（~265+ 次）
- 否定边界："不做X" / "不支持X" / "仅X"（~170+ 次）
- 不确定事项用"待X"标记，而非"可能需要"
