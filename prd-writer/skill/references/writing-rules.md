# PRD 写作规范

## 基础规则

| 规则 | 说明 |
|------|------|
| 不用第一人称 | PRD 是产品规格文档，用"本页面"、"本模块"、被动语态 |
| 结论先行 | 每个段落首句即结论，后面是支撑 |
| 交互规范嵌入模块 | 不单独设"交互规范"章节，在每个模块的描述中内嵌交互细节 |
| 图表嵌入对应章节 | 流程图/时序图/架构图放在对应章节内，不集中到附录 |
| 视觉细节交给设计稿 | 不写具体字号/颜色/间距参数，用"以设计稿为准""具体设计以视觉稿为准" |
| 设计决策仅在方案比选时使用 | 有多方案比选→对比表+推荐结论；日常模块描述不内嵌"采用X而非Y，是因为..." |
| PRD标题格式 | 用全角竖线分隔领域：`{领域}｜{需求名称}`，如"支付成功率｜设备无网支付方案" |

## 交互描述规范

针对每个可交互元素（按钮、输入框、筛选器、弹窗），描述需覆盖：

1. **入口**：用户从哪里进入这个功能，如「点击XX按钮进入」、「从XX页面跳转」
2. **默认状态**：`默认展示当前月度`、`红包浮层默认吸底`
3. **触发动作**：`点击头部时间拉起时间筛选器picker`
4. **行为结果**：`点击后开始推进支付流程，对客进入标准支付页`
5. **取消/关闭**：`点击关闭按钮或点击蒙层，关闭picker，时间不生效`
6. **异常/降级**：`如无法读取到系统版本，则不显示此条的按钮`

**校验规则**（如涉及输入、权限、状态限制）：

| 校验项 | 触发时机 | 报错文案 | 是否阻塞 |
|--------|---------|---------|---------|
| {{校验名称}} | {{什么条件下触发}} | {{用户看到的报错}} | {{是/否}} |

格式约定：
- 按钮文案、功能名、UI元素统一用「」：`点击「确定」按钮`、`显示「去升级」功能按钮`
- 动态内容用 #{}：`最高可减 #{动态金额} 元`
- 可配置项用括号标注：`（2s时间可配）`
- 视觉细节不写具体参数，用"以设计稿为准""具体设计以视觉稿为准"

## 数据表达格式

| 场景 | 格式 | 示例 |
|------|------|------|
| 变化趋势 | X%→Y%（+Zpt） | 80.84%→88%（+7.16pt） |
| 占比数据 | X% | 不到总电量的 0.5% |
| 量级 | 约X万/亿 | 约 2.76 亿量级 |
| 目标对比 | 实验组显著高于/低于对照组 | — |
| 公式定义 | 指标名 = 分子描述 / 分母描述 | 挽回成功率 = 带挽回标记的支付成功订单 / 弹窗曝光pv |

## 特殊符号

| 符号 | 用途 | 示例 |
|------|------|------|
| → | 变化/流程/转化 | 15%→44.32%、入口→教育页→转化 |
| 「」 | UI元素名、功能名、按钮文案 | 「去升级」、「猜你想问」、点击「确定」按钮 |
| #{} | 动态内容占位 | 最高可减 #{动态金额} 元 |
| · | 并列短语 | 解锁才能碰 · 碰到才扣款 · 全程安全守护 |
| — | 解释性破折号 | 百万账户险保障——我们的终极兜底 |
| + | 组合/叠加 | Hero首屏 + 3个内容模块 + 底部 |
| × | 网格/尺寸 | 2×2 卡片网格 |
| > | 引用/补充说明 | > 教育完成率的具体目标值待首轮数据回收后确定基线 |
| ⚠️ | 建议标注 | ⚠️ 建议补一张多状态对比截图 |
| （） | 可配置项/补充说明 | （2s时间可配）、（和支付token一致） |
| ｜ | PRD标题领域分隔 | 支付成功率｜设备无网支付方案 |
| ~~删除线~~ | 已放弃/废弃方案 | ~~涉及多端改造，成本较高~~ |

## 行业术语

自然使用，不需要额外解释的术语：
- 碰一下支付、NFC 近场支付、WebView、H5
- AB 实验、实验组/对照组、分组策略
- UV/PV、完读率、转化率、留存率
- 埋点、曝光、进入视口、IntersectionObserver
- 配置化、接口下发、降级方案

需要首次使用时解释的术语：
- 业务专有概念（如"N 结果页"、"阵地页 A 位/B 位"）
- 内部缩写（如"page_source 参数"）

## PRD 格式规范

### 文档标题格式

使用全角竖线分隔领域：`{领域}｜{需求名称}`，如"支付成功率｜设备无网支付方案"

### 变更记录

使用 H2 标题 `##`，格式：

```markdown
**变更记录**

| 日期 | 变更人 | 版本 | 变更内容 |
|------|--------|------|----------|
| 20260411 | AI 生成 | V1.0 | 初始版本 |
```

### 章节内不重复标题

每个章节（如"一、需求概述"）的正文开头**不要再重复写章节标题**。直接写正文。
