**预期生成的占位符**（4 个）：

1. Demo 页面截图 - 主界面时段视图（5 个会议室×16 个时段）
2. Demo 页面截图 - 预订确认浮层

## 验证清单

运行 prd-writer 后，检查生成的 PRD：

### 占位符格式检查
```
> 📷 **图片占位**：{类型} - {说明}
>
> - 位置：{路径或来源说明}
> - 操作：{手动上传/需截图/需导出/需自制}
```

### 占位符数量检查
- [ ] Demo 页面截图占位符 ≥ 2 个（主界面 + 浮层）
- [ ] 多状态对比图占位符 = 1 个
- [ ] 数据报表截图占位符 ≥ 1 个
- [ ] 总占位符数量 ≈ 4 个

### 可自动生成图表检查
- [ ] 如有 Mermaid 代码，说明流程图已自动生成（不是占位符）
- [ ] 如有 PlantUML 代码，说明时序图/状态机已自动生成（不是占位符）

---

## 通过标准

**全部通过** 需满足：
1. 占位符格式符合规范
2. 4 个预期占位符全部生成
3. 没有多余的占位符
4. 可自动生成的图表已生成代码（如适用）
