# 会议室预订系统 - 技术架构简述

## 系统概述

会议室预订系统，支持钉钉快订、可视化时段选择、自动审批。

## 技术栈

- **前端**：H5 页面（钉钉容器内运行）
- **网关**：API Gateway（鉴权、限流、路由）
- **后端服务**：
  - 预订服务（核心业务逻辑）
  - 会议室服务（会议室管理、时段管理）
  - 审批服务（自动审批规则）
- **数据存储**：
  - MySQL（主数据库）
  - Redis（缓存、分布式锁）
  - RocketMQ（消息队列、异步通知）
- **外部依赖**：
  - 钉钉 API（免登、消息推送）
  - 日历服务（同步到钉钉日历）

## 架构分层

```
用户层（钉钉 H5）
    ↓
网关层（API Gateway）
    ↓
业务层（预订/会议室/审批服务）
    ↓
数据层（MySQL + Redis + MQ）
```
