# 图片占位符规则

## 概述

PRD 中的图片分为两类：

| 类型 | 能否自动生成 | 处理方式 |
|------|------------|---------|
| **流程图/时序图/状态机/架构图** | ✅ 能 | Mermaid/PlantUML 代码生成，语雀原生渲染（用户要求高保真时可选 Fireworks Tech Graph，需导出 PNG） |
| **Demo 截图/多状态对比图/数据截图** | ❌ 不能 | 图片占位符，需手动截图/上传 |

**图片占位符**用于无法自动生成的图片（Demo 截图、设计稿、数据报表截图等）。

### 第一步：判断是否需要占位符

|------|------|---------|---------|

| #9 | ≥3 状态 | 状态机图 | ✅ 自动生成 PlantUML |
| #19 | 需要 | 业务流程图 | ✅ 自动生成 Mermaid |
| #3 | 复杂 | 架构图 | ✅ 自动生成 Mermaid |
| #1 | H5/小程序 | Demo 页面截图 | ⚠️ **占位符** |
| - | 多状态变体 | 多状态对比图 | ⚠️ **占位符** |
| #17 | 多入口 | 用户动线图 | ⚠️ **占位符** |
| #23 | 需要 | 数据报表截图 | ⚠️ **占位符** |

### 第二步：在对应章节插入占位符

| 写作模式 | 占位符插入时机 |
|---------|--------------|
| 模式 A（页面结构） | 描述完整页面后 |
| 模式 B（多状态变体） | 描述每个变体后 |
| 模式 C（复杂链路） | 链路描述完成后 |
| 模式 D（数据指标） | 指标定义后 |

## 占位符格式

```
> 📷 **图片占位**：{类型} - {说明}
>
> - 位置：{路径或来源说明}
> - 操作：{手动上传/需截图/需导出/需自制}
```

### 图片类型

| 类型 | 说明 | 触发条件 |
|------|------|---------|
| Demo 页面截图 | 标注截哪个状态/区域 | #1=H5/小程序 且 有 UI 界面 |
| 多状态对比图 | 需从 Demo 截图二次加工 | 有同组件多状态变体 |
| 用户动线图 | 标注从哪个入口到哪个页面 | #17=多入口 |
| 数据表格截图 | 标注数据来源 | #23=埋点追踪=需要 |

### 操作类型

| 操作 | 含义 | 适用场景 |
|------|------|---------|
| 手动上传 | 图片已存在，需手动上传至语雀 | 已有设计稿/截图 |
| 需截图 | 需手动截取 Demo 特定状态 | 需要展示产品界面 |
| 需导出 | 需从 Demo/设计工具导出为图片 | HTML Demo、Figma 设计稿 |
| 需自制 | 需设计师/产品手动绘制 | 流程图、架构示意图 |

## 示例

### Demo 页面截图

```
> 📷 **图片占位**：Demo 页面截图 - 主界面时段视图，展示 5 个会议室×16 个时段
>
> - 位置：prototype/screenshots/main-view.png
> - 操作：手动上传至语雀
```

### 多状态对比图

```
> 📷 **图片占位**：多状态对比图 - 预订前/中/后三状态对比
>
> - 位置：从 Demo 分别截取空闲/选中/已预订三种状态
> - 操作：需截图后拼接为对比图
```

### 用户动线图

```
> 📷 **图片占位**：用户动线图 - 从钉钉入口到预订完成的全链路
>
> - 位置：需手动截取从点击钉钉入口→选择会议室→确认预订的完整流程
> - 操作：需截图
```

### 数据表格截图

```

>
> - 位置：来自埋点报表 system/analytics/booking-conversion
> - 操作：需导出为图片
```

## 使用规则

1. **图片已存在**：指明路径，说明需手动上传
2. **图片未生成**：说明需要什么图、怎么生成
3. **语雀文档同步**：占位后需手动上传图片并替换占位符
4. **截图验收**：如项目已有 Demo 代码（.html/.vue/.tsx 等）且 Playwright 可用，agent 必须截取 Demo 各状态截图填充占位符，而非仅保留占位符。仅当 Demo 无法访问（需后端 API、需登录态、Playwright 不可用）时才保留占位符并标注原因

**占位符符号统一**：图片占位符统一使用 `📷 **图片占位**` 格式（含类型、说明、位置、操作 4 字段），不使用 `⚠️` 标注图片。`⚠️` 仅用于 PRD 中的风险/待确认标注，不用于图片占位。

**代码块类图表禁止占位**：Mermaid 和 PlantUML 代码块由语雀原生渲染，不得替换为占位符或文字描述。

---

## 与 Mermaid/PlantUML 图表的区别

| 类型 | 工具 | 用途 | 示例 |
|------|------|------|------|
| 流程图/时序图/状态机/架构图 | Mermaid / PlantUML（可选 Fireworks） | 代码生成，语雀原生渲染（Fireworks 需导出 PNG） | ```mermaid flowchart TD ...``` |
| 产品界面截图/设计稿/数据截图 | 图片占位符 | 需手动截图/导出/上传 | `> 📷 **图片占位**：...` |

**判断逻辑：**
- 需要展示真实界面效果 → 图片占位符
- 需要展示抽象流程/结构 → Mermaid/PlantUML 代码生成
