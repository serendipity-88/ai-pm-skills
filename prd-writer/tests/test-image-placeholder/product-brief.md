# 会议室预订系统 - 产品方案简述

## 背景

公司内部会议室预订流程繁琐，需要：
1. 打开钉钉 - 工作台 - 会议室
2. 选择时间、查看可用会议室
3. 填写预订信息
4. 等待审批

## 目标

简化预订流程，实现"快订"体验：
- 可视化时段网格（5 个会议室 × 16 个时段）
- 点击空闲时段直接预订
- 预订成功率高

## 核心功能

### 1. 主界面时段视图

展示 5 个会议室横排，纵向 16 个时段（08:00-24:00），每个格子显示状态：
- 空闲（绿色）
- 已预订（红色）
- 当前选中（蓝色）

### 2. 快订流程

1. 点击空闲格子
2. 弹出预订确认浮层
3. 点击确认
4. 显示成功状态

### 3. 多状态展示

同一会议室格子有 3 种状态：
- 默认空闲态
- 选中态
- 已预订态

## 数据指标

需要追踪：
- 时段视图曝光 UV
- 格子点击率
- 预订转化率（点击→确认）

## 依赖

- 钉钉免登
- 会议室服务 API
- 预订服务 API
