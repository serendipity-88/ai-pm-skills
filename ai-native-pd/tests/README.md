# ai-native-pd 测试用例

## 测试方法

分 Phase 对照测试：每个 Phase 独立测试，对比 skill 执行 vs Claude 裸跑的输出质量。

## 测试用例列表

| # | 用例 | 复杂度 | 测试分流 | 重点测试 Phase |
|---|------|--------|---------|---------------|
| T1 | 内部会议室预订工具 | 轻量 | 急用 | 分流判断 + Phase 3 |
| T2 | 团队知识库搜索工具 | 中等 | 正常 | Phase 1 + 2 + 3 |
| T3 | 竞品监控分析平台 | 复杂 | 论证 | Phase 1 深度调研 |

## 评估维度

### Phase 1 发现
- JTBD 转化质量：是否从功能描述还原到用户场景
- 竞品搜索质量：找到的竞品是否相关、信息是否准确
- 调研摘要结构：是否按模板输出、风险提示是否有价值
- 7 维度评估：能推断的是否自动推断、追问是否精准

### Phase 2 定义
- 场景裁剪：是否收敛到 3 个核心场景
- 范围边界：是否明确"不做什么"
- 产品简报质量：是否可作为 Phase 3 的有效输入

### Phase 3 验证
- Skill 发现：是否正确检测到已安装的相关 skill
- HARD-GATE：是否在 coding 前要求确认
- Iterate 微循环：是否按改→验→决执行

### Phase 4 交付
- prd-writer 衔接：是否顺畅委托、材料是否完整传递

### 流程控制
- 分流判断：是否根据用户意图正确选择路径
- 断点续跑：是否检测到已有文件并跳过
- PM 警戒线：是否避免过度提问、是否允许跳步骤
