# 测试用例：图片占位符生成逻辑

## 用例 ID
`IMG-PLACEHOLDER-001`

## 测试目标
验证 prd-writer skill 在生成 PRD 时，能否正确识别需要图片占位符的场景，并按格式生成占位符。

## 前置条件
- prd-writer skill 已更新并发布（包含图片占位符逻辑）
- 测试材料已准备（demo.html + product-brief.md）

## 测试输入

### 材料 1: demo.html
- 类型：H5 单页面 Demo
- 包含内容:
  - 主界面时段视图（5 个会议室 × 16 个时段网格）
  - 预订确认浮层（点击空闲格子后弹出）
  - 会议室格子多状态（free/booked/selected）

### 材料 2: product-brief.md
- 类型：产品方案简述
- 包含内容:
  - 背景和目标
  - 核心功能描述
  - 数据指标（埋点需求）
  - 依赖说明

## 预期行为

### Phase 1: 维度推断
| 维度 | 预期结果 | 依据 |
|------|---------|------|
| #1 产品类型 | H5 页面 | demo.html 存在 |
| #2 产品规模 | 轻量 | 单页面 |
| #3 复杂度 | 轻量 | 2 个功能模块 |
| #17 用户动线 | 不需要 | 单入口 |
| #23 埋点追踪 | 需要 | 有数据指标 |
| 多状态变体 | 有 | 3 种格子状态 |

### Phase 4: 图片占位符生成
应生成以下占位符：

| # | 类型 | 说明 | 位置 | 操作 |
|---|------|------|------|------|
| 1 | Demo 页面截图 | 主界面时段视图 | demo.html | 需截图 |
| 2 | Demo 页面截图 | 预订确认浮层 | demo.html #booking-modal | 需截图 |
| 3 | 多状态对比图 | 格子三状态对比 | demo.html .time-slot | 需截图后拼接 |
| 4 | 数据报表截图 | 埋点指标定义 | 待标注来源 | 需标注来源 |

### 占位符格式
```
> 📷 **图片占位**：{类型} - {说明}
>
> - 位置：{路径或来源说明}
> - 操作：{手动上传/需截图/需导出/需自制}
```

## 验证步骤

1. 在测试目录下运行 `claude "/prd-writer"`
2. 检查生成的 `prd/PRD_v1.0.md`
3. 搜索占位符：`grep "📷 \*\*图片占位\*\*" prd/PRD_v1.0.md`
4. 验证占位符数量和格式

## 通过标准

- [ ] 占位符数量 ≥ 4 个
- [ ] 每个占位符格式符合规范（类型 - 说明 - 位置 - 操作）
- [ ] Demo 页面截图占位符 ≥ 2 个
- [ ] 多状态对比图占位符 = 1 个
- [ ] 数据报表截图占位符 ≥ 1 个
- [ ] 没有多余的占位符（如流程图等应自动生成的图表）

## 失败场景

| 失败现象 | 可能原因 | 修复方向 |
|---------|---------|---------|
| 占位符数量 < 4 | 维度推断遗漏 | 检查 Phase 1 推断逻辑 |
| 占位符格式不对 | 未遵循规范 | 检查 references/image-placeholder-rules.md |
| 流程图也用占位符 | 未区分图表类型 | 检查图表衍生规则 |
