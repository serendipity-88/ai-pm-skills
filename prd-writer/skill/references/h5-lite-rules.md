# H5 轻量模式写作规范

> 本文件替代 writing-rules.md + forbidden-patterns.md + prd-writing-style-guide.md + core-conventions.md，仅供 H5 轻量模式使用。
> 完整模式和轻量模式仍使用原有 reference 文件。

## 1. 反套写规则

- **从需求推导结构，不从已有PRD套写**——核心判断、利益点、CTA、指标都从截图+用户输入+领域知识推导
- 不加载任何已有PRD作为内容参考
- 不照搬模板中的内容提示——模板只定义章节范围（砍什么留什么），不定义内容怎么写

## 2. 数据表达格式

- 变化趋势：`X%→Y% (+Zpt)`
- 占比：`X%`
- 量级：`约X万` / `约X亿`
- 公式定义：`指标名 = 分子 / 分母`
- 近似值：`pt`（百分点）/ `pp`（百分比点）/ `~`（约）

## 3. 禁用表达

| 禁用 | 替换为 |
|------|--------|
| 我觉得/看起来/可能/应该 | 直接陈述事实 |
| 非常/特别/显著/大量/很多/若干 | 具体数据或删除 |
| 一定能/必将 | 预计/目标值 |
| "本模块解决的核心问题是…" | 事实陈述 |
| 感叹号、emoji | 陈述句 |
| 竞品品牌名（微信支付、抖音等） | "其他支付方式""主流短视频平台" |
| 视觉参数（38px白色加粗字体等） | "以设计稿为准" |

## 4. 情态词

- 用：`支持X` / `需要X` / `不做X` / `仅X`
- 不用：`务必` / `应该`（几乎不用） / `确保`（极少） / `必须`（极少）

## 5. 符号规范

| 符号 | 用途 | 示例 |
|------|------|------|
| `「」` | UI元素文案 | 「去看看」「立即参与」 |
| `#{}` | 动态内容 | `#{用户名}` `#{金额}` |
| `｜` | PRD标题分隔 | `用户增长｜新用户引导方案` |
| `~~` | 删除线（已放弃） | `~~原方案~~` |
| `（）` | 可配置项 | `3s（可配）` |
| `→` | 流程转化 | `入口卡片→引导页→完成` |

## 6. 不确定性分级

| 状态 | 标记 | 示例 |
|------|------|------|
| 已确定 | 直接陈述 | 目标用户规模约50万 |
| 需确认 | `<font color=#DF2A3F>待X</font>` | `<font color=#DF2A3F>待确认</font>` |
| 暂推迟 | `<font color=#8A8F8D>非本期</font>` | `<font color=#8A8F8D>非本期</font>` |
| 已放弃 | `~~删除线~~` | `~~原方案~~` |

## 7. 颜色标注

- `#DF2A3F` 红字：待确认 / 关键数据 / 风险
- `#70000d` + `#f8ced3` 背景：P0 优先级
- `#664900` + `#f6e1ac` 背景：P1 优先级

## 8. H5 专属 scope 规则

| 规则 | 说明 |
|------|------|
| 截图驱动 | 产品方案主体是设计截图+需求说明表，不写"图片占位" |
| 需求1表制 | 所有需求点放在1个表（模块｜说明），用 `+` 列表项，不分小节 |
| 背景极简 | 精简问题陈述+可选根因表，人群数据链接到已有文档不重复 |
| 数据写完整 | 指标表+AB实验表+埋点清单，不偷懒写"同线上" |
| 需求优先级 | P0/P1/P2 分级，用颜色标注（P0 红底、P1 黄底） |
| 砍掉的章节 | 名词解释、配置化设计、演进规划、验收标准、前后对比表、依赖与待定、干系人与分工、范围排除、非功能性需求、风险与应对 |

## 9. 描述格式

H5 轻量模式只用模式A（页面结构描述）。在需求说明表的"说明"列内使用以下格式：

- 组件名做小标题（加粗），后接缩进 bullet list
- 每个 bullet 是独立功能点，1-2行
- 条件逻辑用嵌套 bullet：`+ 如X，则Y`
- 动态内容用 `#{}` 标记
- 交互说明：行内一句话描述，不展开5要素
- 准入条件单独成块，用编号列举
- 视觉细节用"以设计稿为准"，不写具体字号/颜色/间距

## 10. 写作基础

- 不用第一人称：用"本页面""本模块"，不用"我们"
- 结论先行：每段首句即结论，后面是支撑
- 视觉细节交给设计稿：不写具体字号/颜色/间距参数
- 设计决策仅方案比选时使用：日常模块描述不内嵌决策解释
- 章节内不重复标题：正文开头不要再重复写章节标题

## 11. 条件句与决策

- 条件句：用 `如X，则Y`，不用 `如果` `若`
- 做决策不列选项：直接定方案，不写分析过程
