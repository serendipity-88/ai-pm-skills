# 案例参考

## 使用说明

案例展示了 PD Deep Research 产出的实际效果，帮助理解"好的产出长什么样"。

每个案例的完整产出是一个 `research-report.md`，包含三个分层章节：
- **第一层：决策简报** — 1-2 页，纯表格，信息密度最高。含需求衔接小节（为谁解决什么问题/产品定位/边界约束/成功指标）
- **第二层：决策推理** — 每个决策的完整证据链
- **第三层：研究数据** — 行业演变、竞争格局、验证发现等原始研究材料

研究完成后，按消费场景交付：
- **快速决策**：只拿第一层（含需求衔接）
- **向上汇报**：第一层 + 第二层
- **团队讨论**：第一层 + 第二层 + 第三层关键数据
- **完整存档**：全部内容

## 案例列表

### 订阅支付流失挽回（2026-05-06）

- **研究类型**：产品功能
- **竞争场景**：C（竞品众多）——暗黑模式型/合规+折扣型/合规+分层型/无作为型四类
- **核心发现**：挽回策略的核心不是"阻止取消"而是"在取消路径上给出用户真正想要的替代方案"；微信支付已推出"解约挽留"产品但支付宝没有对应能力；72%走到取消入口的用户可被挽留（Churnkey 2025）
- **置信度**：6 高 / 6 中 / 3 待验证
- **产出文件**：`订阅支付流失挽回/research-report.md` + `research-report.html`

### 碰一下小助理（2026-05-06）

- **研究类型**：产品功能定位
- **竞争场景**：B（少量竞品，但有强大间接替代）
- **核心发现**：碰一下小助理的机会不在"对话"而在"诊断+执行"——支付失败场景完全依赖用户自助排查，垂直Agent可覆盖"支付工具"到"支付服务"的关键跃迁
- **置信度**：6 高 / 6 中 / 5 待验证
- **产出文件**：`碰一下小助理/research-report.md` + `research-report.html`
- **备注**：`research-v1-legacy.md` 是旧版方法论的产出，仅供对比参考

### 线下商户私域运营（2026-05-04）

- **研究类型**：市场
- **竞争场景**：C（竞品众多）——5大集群、20+主要玩家
- **核心发现**："支付+AI"是打开1.2亿小微商户私域市场的关键组合，但必须从单一垂直行业切入
- **置信度**：6 高 / 6 中 / 5 待验证
- **产出文件**：`线下商户私域运营/research-report.md` + `research-report.html`
