# P2 内容深化待讨论

本文件记录下一轮内容层面的候选议题，暂不实现。

## 1. PRD Writer 的行业泛化

当前 `prd-writing-style-guide.md` 基于支付类 PRD 训练材料提炼，风格鲜明，但可能对 SaaS、AI 工具、内部系统、内容产品等场景有一定过拟合。后续可考虑把通用 PRD 写法作为默认层，把支付类表达沉淀为可选 profile。

## 2. AI Native PD 的假设账本

当前流程覆盖发现、定义、验证、交付，但缺少贯穿全程的 assumption ledger。后续可增加“我们相信什么 → 如何验证 → 证据是什么 → 是否继续”的结构，让 Demo 验证更像产品决策闭环。

## 3. PD Deep Research 的反证与研究边界

当前研究强调决策导向和置信度标注。后续可进一步补强反方观点、找不到信息本身的含义、证据与推断的边界，让研究 brief 更适合高风险产品决策。
