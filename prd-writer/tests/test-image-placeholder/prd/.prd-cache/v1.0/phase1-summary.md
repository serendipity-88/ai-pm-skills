# Phase 1 项目理解摘要

## 我对项目的理解

**产品**：会议室预订 H5 页面，v1.0

**规模**：轻量（2个模块：时段视图、预订流程）

**核心链路**：用户点击空闲时段 → 弹出确认浮层 → 点击确认 → 显示预订成功

**有状态流转**：空闲 → 选中 → 已预订（3个状态）

> 理解有偏差的地方直接说。
