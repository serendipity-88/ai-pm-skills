# 支付结果页推荐功能方案

## 背景

支付成功页目前仅展示支付结果，流量未被有效利用。目标在支付成功页展示相关推荐内容，提升用户转化。

## 目标

- 推荐点击率目标：5%
- 单页推荐曝光 uv：1000w/天

## 产品方案

### 推荐区展示

位于支付成功金额下方，展开后展示 3 条推荐内容：

1. **推荐内容类型**
   - 商家优惠券：展示当前商家可用券
   - 附近商家：基于定位推荐附近商家
   - 猜你喜欢：基于用户历史行为推荐

2. **交互**
   - 默认收起，点击「展开」展开推荐区
   - 每条推荐点击后跳转对应详情页
   - 不感兴趣可点击「不感兴趣」隐藏该条

### 配置化

- 推荐开关：商家可配置是否展示
- 推荐类型：商家可配置展示哪些类型
- 推荐条数：默认 3 条，可配置 1-5 条

## 数据指标

- 推荐曝光 pv/uv
- 推荐点击率 = 点击 uv / 曝光 uv
- 各类型推荐点击率
