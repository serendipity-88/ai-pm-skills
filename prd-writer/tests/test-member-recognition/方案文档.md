# NFC会员识别方案

## 背景

当前NFC支付场景中，用户在商家处碰手机完成支付后，会员身份需要单独出示会员码，体验断裂。数据显示，约 65% 的会员用户在NFC支付时未出示会员身份，导致商家无法识别会员、用户无法享受会员权益。

目标：在NFC支付链路中自动完成会员身份识别，用户无需额外操作即可享受会员权益。

## 目标人群

- 已开通商家会员的NFC支付用户
- 商家侧：接入NFC支付的品牌商家（约 1.2 万家门店）

## 产品方案

### 1. 会员识别页（H5）

用户碰手机后，在支付准备页展示会员识别状态。页面结构：

- 顶部状态栏：展示会员识别进度（识别中 → 已识别 → 权益匹配）
- 会员信息区：展示会员等级、积分余额、当前可用权益
  - 如用户非该商家会员，展示「一键开通」入口
  - 如会员信息获取超时（3s），展示降级文案「会员信息获取中，不影响支付」
- 权益推荐区：根据订单金额匹配可用权益
  - 有可用优惠券：展示最优券面额和使用条件
  - 有积分抵扣：展示可抵扣金额（具体设计以视觉稿为准）
  - 无可用权益：不展示此区域

### 2. 权益确认弹窗

支付前弹窗确认权益使用：

类型 1 - 有优惠券弹窗：
- 主文案：本单可使用会员优惠
- 副文案：已为您匹配 #{券面额} 元优惠券
- 主按钮：「使用优惠并支付」，点击后自动核销优惠券并推进支付
- 次按钮：「不使用，直接支付」，点击后跳过权益直接支付

类型 2 - 仅积分抵扣弹窗：
- 主文案：本单可用积分抵扣
- 副文案：#{可用积分} 积分可抵 #{抵扣金额} 元
- 主按钮：「使用积分并支付」
- 次按钮：「不使用，直接支付」

类型 3 - 非会员弹窗：
- 主文案：开通会员享专属优惠
- 副文案：本单预计可省 #{预估金额} 元
- 主按钮：「开通并支付」，先开通会员再推进支付
- 次按钮：「跳过，直接支付」

### 3. 会员识别链路

正常链路：
- 用户侧：碰手机后进入支付准备页，同时发起会员识别请求
- 设备侧：感应成功后，将用户uid和商家pid透传给会员服务
- 服务端：收到uid+pid，查询会员关系，3s内返回会员信息和可用权益
  - 如有可用权益，推送权益信息给客户端，弹出权益确认弹窗
  - 如无可用权益，静默跳过，直接进入支付流程

异常链路1 - 会员服务超时：
- 服务端：3s内未返回结果（3s超时时间可配）
- 用户侧：展示降级文案，支付流程不阻塞，会员权益在支付成功后异步补发
- 设备侧：正常推进支付，不等待会员结果

异常链路2 - 会员关系不存在：
- 服务端：查询结果为非会员
- 用户侧：根据商家配置决定是否展示开通入口（待确认：是否所有商家都开放一键开通）

异常链路3 - 权益核销失败：
- 服务端：优惠券/积分核销接口返回失败
- 用户侧：toast提示「权益使用失败，已为您完成支付」，支付金额回退为原价
- 后续：记录核销失败日志，T+1 人工排查

### 4. 配置化设计

商家可在运营后台配置：
- 是否开启NFC会员识别（开关）
- 会员识别超时时间（默认 3s，可配 1-5s）
- 非会员是否展示开通入口（开关）
- 权益优先级：优惠券 > 积分抵扣 > 无权益

接口定义：
```typescript
interface MemberConfig {
  merchantId: string;
  enableMemberRecognition: boolean;
  timeoutMs: number; // 默认 3000
  showJoinEntry: boolean;
  benefitPriority: ('coupon' | 'points' | 'none')[];
}

interface MemberInfo {
  isMember: boolean;
  level: string;
  points: number;
  availableCoupons: Coupon[];
  pointsDeductible: number; // 可抵扣金额，单位分
}
```

### 5. 数据度量

北极星指标：会员权益使用率
- 口径：使用了会员权益（优惠券或积分抵扣）的支付笔数 / 有会员身份的NFC支付总笔数
- 目标：从当前 12%→30%（+18pt）
- 实验对比：实验组（NFC自动识别会员）vs 对照组（需手动出示会员码）

过程指标：
- 会员识别成功率 = 3s内成功返回会员信息的请求数 / 总识别请求数
- 权益匹配率 = 匹配到可用权益的会员支付笔数 / 会员支付总笔数

基础指标：
- 会员识别请求 pv/uv
- 权益确认弹窗曝光率
- 弹窗「使用优惠并支付」点击率
- 「不使用，直接支付」点击率
- 非会员「开通并支付」转化率

分析指标：
- 识别超时率 = 超时请求数 / 总识别请求数
- 权益核销失败率 = 核销失败笔数 / 尝试核销笔数
- 会员开通转化率 = 通过弹窗开通会员的用户数 / 非会员弹窗曝光用户数

AB 实验设计：
- 实验组 A（4000w）：NFC自动识别会员 + 权益弹窗
- 实验组 B（4000w）：NFC自动识别会员 + 静默使用最优权益（不弹窗）
- 对照组（4000w）：当前链路，需手动出示会员码
- 实验周期：14 天
- 核心观测：权益使用率、支付成功率、单笔支付时长

### 6. 已知约束

- NFC 感应后到支付准备页的时间窗口约 800ms，会员识别请求需在此窗口内发出
- 部分老设备（N3/N3C）不支持透传uid，需降级为手动出示会员码
- 会员服务 QPS 峰值约 5000，需评估是否需要扩容

### 7. 不做的事情

- 本期不做跨商家会员识别（仅支持单商家维度）
- 不做会员等级变更提醒
- 不做积分兑换商品（仅支持积分抵扣现金）
- 不做会员信息修改入口
