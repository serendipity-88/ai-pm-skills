# 图片素材处理规则

## 概述

PRD 中的视觉素材分为两类：

| 类型 | 能否自动生成 | 处理方式 |
|------|------------|---------|
| **流程图/时序图/状态机/架构图** | ✅ 能 | Mermaid/PlantUML 代码生成，语雀原生渲染（用户要求高保真时可选 Fireworks Tech Graph，需导出 PNG） |
| **Demo 截图/多状态对比图/数据截图** | 取决于当前 CLI/MCP 能力 | 有素材且平台支持上传/插入时直接引用；有素材但能力不足时保留占位说明；无素材时不主动生成占位 |

图片占位符只用于一种情况：**项目已有截图或图片素材，但当前文档平台 CLI/MCP/API 不支持上传、插入或回读校验**。如项目没有截图素材，不主动生成图片占位。

---

## 占位符插入逻辑

### 第一步：判断是否需要处理图片

根据 `dimensions.yaml` 中的维度结果判断：

| 维度 | 结果 | 图表类型 | 处理方式 |
|------|------|---------|---------|
| #29 | 多端 | 时序图 | ✅ 自动生成 PlantUML |
| #9 | ≥3 状态 | 状态机图 | ✅ 自动生成 PlantUML |
| #19 | 需要 | 业务流程图 | ✅ 自动生成 Mermaid |
| #3 | 复杂 | 架构图 | ✅ 自动生成 Mermaid |
| #1 | H5/小程序且已有截图 | Demo 页面截图 | 按平台能力上传/引用；能力不足时占位说明 |
| - | 已有多状态截图 | 多状态对比图 | 按平台能力上传/引用；能力不足时占位说明 |
| #17 | 已有用户动线图 | 用户动线图 | 按平台能力上传/引用；能力不足时占位说明 |
| #23 | 已有数据截图 | 数据报表截图 | 按平台能力上传/引用；能力不足时占位说明 |

如未找到对应图片素材，跳过图片处理，不新增占位。

### 第二步：检测文档平台图片能力

在发布到语雀、飞书、钉钉、Notion 或其他平台前，先探测当前可用能力：

| 平台 | 图片能力 | 处理方式 |
|------|---------|---------|
| **语雀** | `yuque` CLI `--upload-images` | Markdown 中用相对路径引用本地图片（`![](./images/xxx.png)`），CLI 自动上传到语雀图床并替换路径。需 `cd` 到 Markdown 文件所在目录执行。仅支持 Doc 类型，Sheet/HtmlDoc 不支持。MCP API（`skylark_*`）不支持图片上传 |
| **飞书/钉钉/Notion** | 取决于对应 CLI/MCP | 检测是否支持图片上传 + 文档插入；支持则上传引用，不支持则保留占位说明 |
| 只支持本地 Markdown | — | 使用相对路径或本地路径引用图片 |
| 无法确认能力 | — | 保守处理：保留本地图片路径和占位说明 |

**语雀图片上传工作流**：

```
项目目录/
  ├── prd/
  │   ├── PRD_xxx_v1.0.md    ← Markdown 正文
  │   └── images/
  │       ├── screenshot.png  ← 正文中引用 ![](./images/screenshot.png)
  │       └── diagram.png
```

1. PRD 写作时，截图素材放入 `prd/images/` 目录
2. Markdown 中用相对路径引用：`![描述](./images/xxx.png)`
3. 发布时使用 CLI：`cd prd && yuque update doc <namespace>/<slug> --body-file ./PRD_xxx_v1.0.md --upload-images --yes`
4. CLI 自动完成：解析图片引用 → 上传到语雀图床 → 替换 Markdown 中的本地路径 → 更新文档

### 第三步：在对应章节处理图片

| 写作模式 | 占位符插入时机 |
|---------|--------------|
| 模式 A（页面结构） | 描述完整页面后 |
| 模式 B（多状态变体） | 描述每个变体后 |
| 模式 C（复杂链路） | 链路描述完成后 |
| 模式 D（数据指标） | 指标定义后 |

如果平台支持图片插入，则插入真实图片引用；如果平台不支持但素材存在，才插入占位说明。

## 占位说明格式

```
> 📷 **图片占位**：{类型} - {说明}
>
> - 位置：{路径或来源说明}
> - 操作：{手动上传/需截图/需导出/需自制}
```

### 图片类型

| 类型 | 说明 | 触发条件 |
|------|------|---------|
| Demo 页面截图 | 标注截哪个状态/区域 | #1=H5/小程序 且 有 UI 界面 |
| 多状态对比图 | 需从 Demo 截图二次加工 | 有同组件多状态变体 |
| 用户动线图 | 标注从哪个入口到哪个页面 | #17=多入口 |
| 数据表格截图 | 标注数据来源 | #23=埋点追踪=需要 |

### 操作类型

| 操作 | 含义 | 适用场景 |
|------|------|---------|
| 手动上传 | 图片已存在，需手动上传至目标文档平台 | 已有设计稿/截图但平台能力不足 |
| 需截图 | 需手动截取 Demo 特定状态 | 需要展示产品界面 |
| 需导出 | 需从 Demo/设计工具导出为图片 | HTML Demo、Figma 设计稿 |
| 需自制 | 需设计师/产品手动绘制 | 流程图、架构示意图 |

## 使用规则

1. **图片已存在**：指明路径，说明需手动上传
2. **图片未生成**：说明需要什么图、怎么生成
3. **平台同步**：目标平台支持图片能力时优先上传和引用；不支持时才保留占位说明
4. **截图验收**：如项目已有 Demo 代码（.html/.vue/.tsx 等）且当前 CLI 能力支持截图，可截取 Demo 各状态截图并引用。仅当 Demo 无法访问（需后端 API、需登录态、截图工具不可用）或平台不支持图片上传时，才保留占位说明并标注原因

**占位符符号统一**：确需占位时，统一使用 `📷 **图片占位**` 格式（含类型、说明、位置、操作 4 字段），不使用 `⚠️` 标注图片。`⚠️` 仅用于 PRD 中的风险/待确认标注，不用于图片占位。

**代码块类图表禁止占位**：Mermaid 和 PlantUML 代码块由语雀原生渲染，不得替换为占位符或文字描述。

---

## 与 Mermaid/PlantUML 图表的区别

| 类型 | 工具 | 用途 | 示例 |
|------|------|------|------|
| 流程图/时序图/状态机/架构图 | Mermaid / PlantUML（可选 Fireworks） | 代码生成，语雀原生渲染（Fireworks 需导出 PNG） | ```mermaid flowchart TD ...``` |
| 产品界面截图/设计稿/数据截图 | 图片占位符 | 需手动截图/导出/上传 | `> 📷 **图片占位**：...` |

**判断逻辑：**
- 需要展示真实界面效果 → 图片占位符
- 需要展示抽象流程/结构 → Mermaid/PlantUML 代码生成
